# Prompter Mic Test

Made by Unmesh Khare for Graviton.

Throw-away test app. Question it answers: can a floating box on an Android phone/tablet keep hearing
you (offline, English, Vosk) while a camera app is recording video?

Build: push this folder to a GitHub repo (branch `main`). GitHub Actions builds the APK and attaches it
to a Release called "Build N". Download `app-debug.apk` on the phone and install it.
